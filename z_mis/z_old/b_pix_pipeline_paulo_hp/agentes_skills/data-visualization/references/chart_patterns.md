# Padrões de Gráficos

## Séries Temporais

Usar linha com marcadores discretos, ticks reduzidos no eixo X e unidade clara no eixo Y.

## Valores Monetários

Para grandes volumes, dividir por 1 bilhão e rotular como `R$ bilhões`. Para ticket médio, formatar como reais.

## Rodapé

Adicionar fonte dos dados. Em cenários estimados, adicionar observação explícita de hipótese.

## Destaques

Anotar o maior valor com texto curto e seta simples. Evitar anotar todos os pontos.
