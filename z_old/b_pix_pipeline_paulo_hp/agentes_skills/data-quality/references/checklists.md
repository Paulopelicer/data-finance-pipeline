# Checklists de Qualidade de Dados

## Estrutura

- README existe.
- requirements existe.
- scripts principais existem.
- notebooks esperados existem.
- camadas Bronze, Silver e Gold existem.

## Dados

- Bronze possui registros.
- Silver possui registros.
- Gold possui registros.
- Colunas críticas presentes.
- Tipos numéricos convertidos.
- Datas padronizadas.

## Apresentação

- Gráficos existem.
- Títulos e eixos estão claros.
- Unidades estão explícitas.
- Fonte e limitações estão documentadas.
