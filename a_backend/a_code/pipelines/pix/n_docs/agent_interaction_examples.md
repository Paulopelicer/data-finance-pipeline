
```text

```

```text

```

```text
Use a skill classification-modeling para criar um modelo de classificacao com matriz de confusao e metricas accuracy, precision, recall e f1-score.
```

```text

```

```text
Use a skill pix-pipeline-generator para gerar ou revisar um pipeline completo do Pix com Bronze, Silver, Gold, EDA, ML, metricas, documentacao, testes, graficos e MCP CSV.
```
